# PBL3 VLE9 — Secure DevOps (DevSecOps) Implementation in a Healthcare System

**Project:** CareFlow Pro

**Objective:** Demonstrate security checks integrated into a CI/CD pipeline for a containerized healthcare management demonstration application.

## Modules
1. Authentication and role-based navigation
2. Dashboard metrics
3. Patient management and search
4. Doctor directory
5. Appointment booking and status changes
6. Medical notes
7. Billing records
8. Audit trail
9. DevSecOps information page

## DevSecOps evidence to capture
- Successful pytest run
- Bandit SAST report
- pip-audit report
- Trivy image scan report
- Jenkins pipeline stage view
- Kubernetes deployment, service and pod status
- CareFlow dashboard and modules

## Scope caveats
This is an academic demo with fictional data. Security scan execution is part of the supplied Jenkinsfile but must be run and verified on your AWS environment. The app has no live vulnerability count integration. No compliance certification is claimed.
